# Карен — Android голосовой помощник

MVP Android-приложения с красно-белым оформлением и нейтральной паучьей эмблемой. Оно запускает плавающую кнопку поверх других приложений; касание кнопки включает голосовой ввод.

## Возможности

- открытие приложений по их отображаемому имени;
- переход на домашний экран (Android не разрешает обычному приложению принудительно закрывать другие приложения);
- изменение громкости и яркости после разрешений;
- ответ голосом на вопрос о времени;
- запрос системного разрешения на скриншот / запись экрана;
- фоновая плавающая панель с уведомлением, пока она включена.

## Сборка

Откройте папку в Android Studio Hedgehog или новее, установите Android SDK 35 и запустите `app`. После установки откройте приложение и предоставьте разрешения по подсказкам.

## Важные ограничения Android

Android требует отдельное системное подтверждение на каждый захват экрана или запись и не позволяет стороннему приложению закрывать произвольные приложения. Для глобальной горячей клавиши или жеста вне панели нужны Accessibility Service или системные права; в MVP используется безопасная плавающая кнопка.

Голос — стандартный Android Text-to-Speech; проект намеренно не копирует голос персонажа или актрисы.
